Распределение задач по проекту:
Студент 1 — Интерфейс (crypto_app.rb) Спроектировал главное окно на Tk, реализовал выбор монет и валют, а также добавил переключатель темной и светлой тем для удобства пользователя.
Студент 2 — Работа с API (api_client.rb) Настроил получение данных с CoinGecko, прописал доступные криптовалюты и логику конвертации цен из USD в рубли и евро.
Студент 3 — Аналитика (analyzer.rb) Реализовал расчет средней, минимальной и максимальной цены за неделю, месяц и год. Добавил определение тренда (рост/падение) в процентах.
Студент 4 — Отрисовка графиков (chart_drawer.rb) Создал модуль визуализации, который на основе цен за последние 30 дней строит динамический график на холсте приложения. Выборка и изучение библиотек для работы с графиками и приложениями
Студент 5 — Расчет прибыли (portfolio.rb) Разработал функцию «Машина времени», которая вычисляет, какой доход или убыток получил бы пользователь, вложив $100 в крипту год назад. Произвёл выборку криптовалют, подготовил архитектуру проекта.
