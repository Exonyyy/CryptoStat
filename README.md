# 🚀 CryptoVision: Аналитический трекер криптовалют

Приложение на **Ruby**, предназначенное для мониторинга курсов, анализа исторических данных и визуализации рыночных трендов в реальном времени.

---

## 📋 О проекте
Проект представляет собой комплексный инструмент для работы с криптоактивами. Система объединяет графический интерфейс, интеграцию с внешними финансовыми API и модули статистической обработки данных.

### Ключевые возможности:
* **Мониторинг курсов:** Получение актуальных данных в USD, RUB и EUR.
* **Глубокая аналитика:** Расчет волатильности (Min/Max) и средних цен.
* **Визуализация:** Построение динамических графиков за 30 дней.
* **Инвестиционный анализ:** Функция «Машина времени» для оценки ретроспективной прибыли.
